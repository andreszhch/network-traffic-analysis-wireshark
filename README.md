# Network Traffic Analysis with Wireshark

## Overview
Captured and analyzed live network traffic to identify 
potential security threats and anomalies.

## What I did
- Captured HTTP, HTTPS, and DNS packets in a live network
- Filtered traffic using Wireshark display filters
- Identified anomalies such as unusual packet sizes and 
  suspicious connections
- Evaluated potential security risks from the captured data

## Tools Used
- Wireshark

## Skills Demonstrated
- Network protocol analysis (TCP/IP, DNS, HTTP/HTTPS)
- Threat identification
- Security risk assessment
